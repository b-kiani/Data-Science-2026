# Python for Data Science - TW01 to TW07 Assignment Pack

This solution-free pack is written for students who began with no programming experience. It contains exactly five challenges per week.

## Contents

- 7 weekly Jupyter assignment notebooks
- 7 separate black-and-white PDF instruction sheets
- 35 total challenges
- 100 marks per week
- supplied practice data and a data dictionary
- requirements file and SHA-256 manifest

## Student workflow

1. Extract the complete ZIP.
2. Start JupyterLab from the extracted assignment folder.
3. Open the assignment notebook for the correct week.
4. Run the environment-check cell.
5. Complete all five challenges.
6. Restart the kernel and run every cell from the top.
7. Submit the completed notebook with outputs visible.

No solutions are included. SQLAlchemy is required for the database assignment in TW07.
