# Course data dictionary

## Import-format examples

- sample_notes_utf8.txt: UTF-8 text with an accented word.
- sample_notes_latin1.txt: Latin-1 text for an encoding exercise.
- sample_sales.csv: eight clean sales rows.
- sample_workbook.xlsx: Sales and Regions worksheets.
- sample_records.json: nested customer records.
- sample_table.pkl: trusted local pandas table for the pickle lesson.
- sample_sales.csv.gz: gzip-compressed CSV.
- sample_bundle.zip: ZIP archive containing a CSV and README.

## Analysis datasets

- business_sales_dirty.csv: retail transactions containing missing values, duplicates, mixed date formats, inconsistent category labels, and deliberate range errors.
- monthly_sales.csv: 60 monthly observations with trend, seasonality, and three missing sales values.
- customer_churn.csv: synthetic labelled classification data; churn is the target.
- customer_segments.csv: synthetic customer features with a reference segment reserved for teaching validation.

All records are synthetic and contain no personal or confidential information.
