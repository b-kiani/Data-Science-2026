# Python for Data Science — TW9 to TW17 Assignment Pack

This student pack contains nine solution-free Jupyter assignments and nine separate
print-friendly black-and-white instruction PDFs. Each week has exactly five
challenges worth 20 marks each.

## Package contents

- 9 weekly Jupyter notebooks
- 9 separate black-and-white PDF assignment sheets (4 pages each)
- 45 challenges in total
- 13 supplied data/reference files
- Python package requirements
- SHA-256 integrity manifest

## Weekly sequence

| Week | Topic |
| --- | --- |
| TW9 | Statistical Thinking for Data Science |
| TW10 | Importing Data in Python |
| TW11 | Cleaning Imported Data |
| TW12 | Data Visualization |
| TW13 | Applied Data Pre-processing Case Study |
| TW14 | Supervised Machine Learning |
| TW15 | Unsupervised Machine Learning |
| TW16 | Handling Time-Series Data |
| TW17 | Final Project Presentations and Review |

## Student workflow

1. Extract the ZIP while preserving its folder structure.
2. Start JupyterLab from the extracted assignment folder.
3. Open the notebook for the assigned week.
4. Run its environment and data checks.
5. Complete all five challenges in the marked code cells.
6. Add concise explanations and interpretations where requested.
7. Restart the kernel and run all cells before submission.
8. Submit the completed notebook with outputs visible.

The PDFs are student instruction sheets; all coding work should be completed in
the corresponding notebooks. No solutions or answer keys are included.

## Setup

```bash
python -m pip install -r requirements.txt
jupyter lab
```

All datasets are synthetic and intended only for teaching. Do not open unknown
pickle files; the included sample pickle was generated locally for this course.
